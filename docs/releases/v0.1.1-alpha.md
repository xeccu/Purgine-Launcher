## Instalación
Descarga **Purgine-Setup-Windows.exe** (en *Assets*), ábrelo y pulsa **Instalar**. Si ya tienes Purgine 0.1.0-alpha, verás el aviso «Nueva versión disponible» al iniciarlo: pulsa **Actualizar ahora** y se actualiza solo.

## Novedades
- **Desinstalar siempre disponible** en los juegos instalados (menú del juego y ficha → «Desinstalar…»), aunque tengan una actualización pendiente o atascada: se cancela antes y se borra la carpeta para liberar espacio.
- **Tamaño real en disco**: la ficha de cada juego instalado muestra lo que ocupa de verdad su carpeta («En disco»).
- **Epic Games**: el tamaño de los juegos no instalados sale del manifiesto de la versión actual (antes podía mostrarse un tamaño antiguo).
- El instalador se llama siempre **Purgine-Setup-Windows.exe** y las versiones se publican automáticamente con GitHub Actions.
- Las notas de cada versión se muestran limpias en el aviso de actualización.
